# mVISTA-like-Python-Script-for-MSA-
This is an Python Script made with the AI Claude (Antrhopic) with the Sonnet 5.5 algorithm.
Its goal is to make an image with all the combinations of pair-alignments with the sequences present in your MSA based on a reference (A  sequence of your MSA) that you can mark its genomic regions, for them to be colored in the pair-alignments.
